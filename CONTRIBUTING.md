# Contributing

Thanks for helping. Please:

1. Open an issue first for new components or token changes, so we can agree on the need.
2. Read [docs/principles.md](docs/principles.md) and [docs/adding-a-component.md](docs/adding-a-component.md).
3. Keep changes small and focused. Run `./gradlew :designsystem:test :designsystem:lint :sample:assembleDebug`.
4. Include screenshots (light and dark) for visual changes.
5. Only submit work you have the right to contribute. Do not copy code, assets, tokens or documentation from
   proprietary or internal systems, including those of any current or former employer.
